# 实验 Handoff 入口与执行约定

2026-11-07。当前没有 ready 的首次真实实验 handoff。[TEMPLATE.md](TEMPLATE.md) 是模板，不能直接执行。先阅读 [执行总览](../EXPERIMENT_EXECUTION_PLAN_ZH.md) 和 [就绪清单](../EXPERIMENT_READINESS_ZH.md)。

## 每次实验怎样交接

在本目录新增对应实验的版本化 Markdown，引用公共模块和共同协议，不复制一套算法。文件名可采用“顺序号_实验名_v版本.md”；同实验的预设重复运行可列在同一 handoff 中，各有独立 run_id。恢复一次原运行不自动增加新的实验定义或随机重试机会。

| 状态 | 含义 | Claude 行为 |
|---|---|---|
| draft | 配置、入口、预算或检查尚不完整 | 用于准备，不派发昂贵真实任务 |
| ready | 入口已实现、协议已冻结、输入/授权/资源可核对 | 通过启动检查后按步骤执行 |
| retired | 由新版本替代，或已作为历史交接保留 | 保留原文件，不拿它描述新的运行 |

运行中的 running/completed/blocked/interrupted/failed 等状态写入实验输出，不通过修改 Git 中的 handoff 来记进度。Handoff 从 ready 到启动仍需检查真实服务器条件；ready 不是已完成服务器验收的证明。

## Claude 的共同执行流程

1. 阅读项目 AGENTS、指定 handoff 和对应配置；确认状态及范围，区分开发任务、数据准备、mock 和真实执行。
2. 核对源代码、环境、配置和输入资产。Handoff 与代码一起提交时，允许启动时将干净 checkout 的 HEAD 一次解析为完整 commit，并写入运行锁；不要在同一提交文件中硬填它自身尚不存在的 SHA。也可预先指定已存在的 commit/tag。
3. 默认采用用户确认的串行单源码目录：确认前一运行及其子任务均结束、状态与结果已保存，再在更新入口更新代码。旧作业仍运行、并行对照或恢复旧版本时，使用固定 commit 的独立目录/环境。无需每个实验另建 Git 分支。
4. 生产前检查既有共享资产，按 key+manifest hash 验证。命中则复用并写消费回执；缺失/不匹配只在本 handoff 授权的范围及预算内生产，不能改旧资产或强行伪造命中。
5. 冻结 resolved config、源码/环境身份、handoff 文件 hash、资产引用和 run_id。代码只管理结果引用；数据、权重、缓存、凭据与运行结果放独立存储或忽略目录。
6. 运行本 handoff 列出的已实现命令/入口。常规资源定位、依赖核验和限定次数的基础设施重试自主完成并记账；不因普通步骤反复要求人工确认。缺权限/凭据、资源不足或缺必填科学定义时输出 blocked，说明事实与恢复点。
7. 按确定性规则检查完成状态，产出统一完成摘要和结果入口。任务真实失败、环境异常、缺失指标和 mock 结果分别记录；不删失败题，不以 mock 顶替真实执行。

默认不替用户 commit/push/merge，不覆盖旧输出，不提高预算，不按最终测试选择模型或策略。数值实现/协议需要改动时，保留旧证据并走新的运行定义，不在原运行中静默热修后续算。

## Handoff 必须交代的内容

- 唯一目标、模式与范围，是否允许数据获取/API/真实模型/容器，使用哪些资源。
- 源码解析方式、固定环境、具体已存在的执行入口，以及配置与协议的内容身份。
- 每个 run 的 seed、预算、停止/接收/重试规则；哪些资产可复用、缺失时是否允许生产。
- 固定绝对 storage_root、共享资产位置、独立输出目录，以及已有 run 的恢复条件。
- 成功/失败/blocked 的判断、每阶段 checkpoint、实际费用、结果文件及验收命令。
- 最后给师兄看哪个摘要和报告，哪些是真实完成、哪些仍未验收。

## 统一输出约定（待首次实验入口落实）

建议每个输出根包含 frozen-inputs.json、handoff 原文快照及 hash、执行/费用/恢复日志，以及 completion.json。completion 至少列出 run_id、状态、resolved commit/source/env/config/handoff 身份、输入/输出资产、当前模型、实际成本、失败/阻塞原因、可恢复位置和结果索引。

实际指标文件沿用对应模块格式，不在 handoff 中编造分数或生成“成功”空壳。统一 completion/结果汇总尚待首次实验控制入口实现；现在没有一个现成 run-experiment 命令可自动完成这些步骤。

未来给 Claude 的启动文字只需明确：

```text
阅读 AGENTS.md、docs/handoffs/README.md 和本次指定的 ready handoff。
核对版本、配置、资产、执行授权及服务器资源后，完成该 handoff。
常规步骤自主执行，保留完整状态/费用；无法继续时报告具体 blocked 原因和恢复点。
结束后返回 completion 和结果索引的绝对路径。不要自行改研究协议或提交推送 Git。
```

这段是后续交接用语；当前模板未填、首次入口未实现时不代表已授权立即开展真实实验。
