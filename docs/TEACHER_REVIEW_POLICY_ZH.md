# Teacher 复核开关

本页覆盖旧文档中“默认抽检 5% ＋争议项复核”的默认行为。新试标和正式准备模板均为 `review_mode: off`。

在 `configs/preparation/teacher-pilot.template.json` 或 EXP001 的 workstation bindings 顶层设置：

```json
"review_mode": "off"
```

| 设置 | 第二次模型调用 |
| --- | --- |
| `off` | 不调用复核模型，包括低置信度和随机抽检项 |
| `flagged` | 仅程序校验失败、低置信度、技能不确定及已有争议规则命中的样本 |
| `sampled` | 上述异常项＋现有规则的随机抽检；正式抽检比例沿用 ontology，微型试标抽首条 |
| `all` | 每条标注都复核；整组请求中的每条轨迹也分别复核 |

开启任一模式需要配置 `review_teacher`（沿用 Flash）。关闭时保留该配置无妨，不创建或调用复核客户端。旧的直接集成若未传此字段，保留此前 sampled/可选 reviewer 的兼容行为；请显式设置以免歧义。

关闭复核仍执行 schema、ID、原文证据及监督区间等程序检查。不合格标注进入 blocked，不能被当成无技能样本直接删除。无法消除的技能不确定性保留不确定状态；关闭复核不等于已经核实语义正确。试标后仍建议人工检查真实原文和证据。

每条 provenance 记录 `review_mode`、`review_status`（disabled/not_selected/reviewed）、触发原因及实际复核回执。切换模式请开新的准备/试标输出目录，不改写过去结果；精确请求匹配时可复用已有主标注缓存。准备阶段意图锁绑定该开关。
